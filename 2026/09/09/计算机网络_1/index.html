计算机网络基础概念

主要问题

计算机网络课程主要探讨四个对象，包括网络中存在的对等实体——谁与谁通信，计算机网络所要实现的服务——能提供什么，以及应用的相关协议——按照什么规则通信，和实现与管理——具体怎么做出来并让他持续运行

可以一定程度上简要讨论一下

对等实体

存在网络中的实体并不只是你我，这样通过主机交流的两个真实存在，也就是不能单单将接入网络的电子设备当成实体，否则无法体现对等。其实稍加了解，可以知道计算机通信通过TCP/IP协议进行交流，每个主机在网络上的存在其实可以被剖解成由上到下多层的存在，交流中原始信息也会顺次被每一层封装，发送到网络中，然后到达目的节点时由下到上又依次拆包直到露出内部信息。网络中的每一个主机实体在不同层级采用的协议一致，都遵循相同的规则，所以同层的存在属于相同的协议层，并承担对应相同的功能，也就是对等的实体。由此观之，实则通信的本质是不同节点上的对等实体，也就是对等层通过协议进行逻辑通信。

服务

在有了不同层级的实体概念后，需要讨论，不同层对于他的上下层有什么作用？这就是这些层级所要提供的服务。具体遵循，上一层使用下一层提供的服务，下一层通过自己的协议实现这个服务。具体每一层的作用后续中继续讨论

协议

这一层强调的就是对等实体之间到底怎么交流。因为网络通信是一个巨大的包装并解包过程，对于一个对等实体而言，他们通信时发出的东西和接收时接受的东西是同一结构的；通信时由上层接收的和接收时向上层发送的东西也是同一结构的，协议描述的就是对于这一层级而言他该怎么包装或者解包，同时定义好这一层信息的相关发送、处理规则。协议规定的内容包括：

  • 消息格式：数据长什么样？
  • 消息含义：每个字段是什么意思？
  • 发送时机：什么时候发送？
  • 接收规则：收到以后怎么处理？
  • 异常处理：丢包了怎么办？
  • 状态转换：什么时候进入什么状态？

需要与服务相区分，协议重点关注对等实体所共同遵循的规则，而服务重点关注下层要向上层提供什么服务，也即服务是垂直的，协议是水平的。

实现与管理

上述描述了理论上的网络结构，这一部分的内容则需要解决现实中该如何构造一个网络系统，该讨论物理具体实现的方式，定义协议到底怎么实现？网络怎么配置？怎么运行？怎么维护？即如何通过软硬件实现协议、如何配置网络、如何使网络正常运行，以及如何对网络进行监控、维护和管理。

网络的类别

接下来了解我们身边一般定义的网络都有哪些。一般网络可按覆盖范围划分，可以分成四类网络。需要注意这样划分的网络只是直观的划分依据，并非严格有覆盖面积的划分标准

个域网（PAN）

个域网（PAN, Personal Area Network）是围绕个人建立的小范围网络。典型范围通常是：几厘米到几米，主要服务于一个人的个人设备之间的通信。

常规可见的有NFC、蓝牙等常见的近距离通信技术

局域网（LAN）

局域网（LAN, Local Area Network）是我们日常接触最多的一类网络。它用于连接一个相对有限的地理区域内的大量计算机和网络设备，一般家庭用网络就是局域网，我们一般用的“Wi-Fi”就是局域网的一种实现技术

城域网（MAN）

城域网（MAN, Metropolitan Area Network），可以理解成：覆盖一个城市或城市区域的网络。它的覆盖范围比 LAN 大，但通常又没有 WAN 那么广，一般由若干个LAN组成

广域网（WAN）

广域网（WAN, Wide Area Network）是覆盖范围最大的这一类。它可以跨越：城市、省、国家、大洲、甚至全球，我们现在使用的Internet互联网就是典型的全球性互联广域网络（这里需要关注Internet、internet、WAN是三个不同的东西）

总之，网络并不是一个巨大的、单一的网络，而是大量不同规模、不同所有者、不同技术的网络彼此互联形成的“网络的网络（network of networks）”。

网络的结构

网络边缘

这个元素代表通信的起点和终点的在哪里，也就是网络中直接产生和消费数据的终端设备以及运行在这些设备上的应用，这些设备被统称为端系统（End System）或主机（Host）。应该明白，网络边缘不只是“电脑”，而是强调通信的端点

主机

主机（Host）是一个设备/节点层面的概念，例如：个人电脑、手机、服务器等，它们作为网络通信的端点，能够运行网络应用、产生和接收网络数据。其功能是容纳应用程序，也即主机是网络应用运行的载体，也是网络通信的端点。主机内部大致可以分为三部分：网络硬件、内核软件、用户软件。

网络硬件

**网卡（Network Interface Card, NIC）**是主机连接网络的硬件接口。例如有线以太网卡、Wi-Fi网卡、手机的蜂窝网络接口，这些都可以理解为网络接口设备，负责主机与外部网络之间的数据发送与接收。

一台主机可以拥有多张网卡，而每个网卡对应其全球唯一的MAC地址。

内核软件

主机上的各种软件进程无法直接调用网卡实现网络服务，而是需要间接的借助网卡的内核驱动来调用网卡实现功能，承担了一个中间协调者的角色。因为不同厂商开发的网卡的硬件接口和操作方式可能不同，也就需要不同的网卡驱动进行调用，最终实现一个通用的外部软件的调用接口。网卡驱动对外部软件的接口是统一的，这样外部软件只用实现网卡驱动的调用，不用关心不同网卡有怎样的调用方式

用户软件

这就是上述调用内核软件、网卡驱动的外部软件。这类程序通常不直接操作 TCP/IP 协议栈，而是使用操作系统提供的Socket API，简要提及一下，Socket API 是操作系统向应用程序提供的网络编程接口，使应用程序能够使用操作系统提供的网络通信能力，而无需直接处理底层网络协议和硬件。。这样应用程序不需要自己实现 TCP/IP 协议，而是通过 Socket API 向操作系统请求网络服务，具体的 TCP/IP 协议处理由操作系统内核中的网络协议栈完成。

主机的命名

主机在三个层次上可以有三个名字MAC地址、IP地址、主机名，分别定义主机数据链路层接口的标识，网络层上的接口标识，方便人类记忆使用的名字，关于他们的详细认知后续再描述

网络边缘仍可根据其在某次网络通信中所扮演的角色细分为两类：

客户端

一次网络服务中，向网络发送服务请求的实体。例如chrome、手机App这些都是客户端，浏览器建立在HTTP协议的基础上向web服务器发送了服务请求。此时浏览器就是客户端。也就是需要明晰客户端通常是运行在主机上的应用程序/进程，而不是主机本身，因为发送请求的往往不是主机本体，而是运行在上面需要网络提供服务的程序，这个思想同样可以迁移到对“服务器”的认识。

服务器

一次网络服务中，响应其他端系统的请求并提供服务的实体，例如web服务器这些。

需要注意，服务器和客户端的身份并非固定在某一个主机上，而是看他在某一次网络服务中所充当的角色而定。

接入网

了解了网络边缘成分，接下来需要了解链接网络边缘的成分，也就是构成网络的“边”——这些终端设备怎么进入互联网。这就是接入网，也即链接端系统与网络核心的网络。

接入网需要实现将某个主机连接到边缘路由器上，而边缘路由器就是端系统host去往任何其他远程端系统的路径上的第一台路由器

物理介质

在网络具体信息传播的时候，发射机与接收机之间的物理介质上传播的最小单元是位，即bit（比特），而传递信息的实体即为具体的物理介质，介质分为两种

引导型介质

存在一个物理路径约束信号传播。典型的介质有双绞线、同轴电缆、光纤等

  • 双绞线

两根绝缘铜线相互缠绕形成一对(降低电磁干扰和串扰)
电话线：一对双绞线
网线：四对双绞线，广泛应用于计算机网络双向传输
网线接口：水晶头

  • 同轴电缆

两根同心铜导线，双向传输，电缆上的多个频率通道，带宽可达100Mbps。
注：同轴电缆采用了频分复用的技术，使得不同频率范围可以承载不同信号，因此同一条物理线路可以同时承载多个信道。

  • 光纤

光纤利用光信号承载数字数据
特点：

  • 带宽高
  • 抗电磁干扰
  • 传输距离长
非引导性介质

此类介质无需物理导线实体作为信号传播路径，也即无线电信号。其通过电磁频谱中各种“波段”携带信号，不依赖介质的传播。一般采用半双工的传播方式，包含类型简单列为下表

类型 典型技术 覆盖范围
短距离无线 Bluetooth 几米～几十米
无线局域网 Wi-Fi 房间、建筑、局部区域
蜂窝网络 4G/5G 城市/广域
地面微波 微波链路 较长距离点对点
卫星通信 卫星链路 极广区域

接入网方式

讨论现实具体应用接入网的实例

接入方式 使用的主要介质 基本原理 主要特点
DSL 电话双绞线 利用电话线传输数字数据 可同时传输语音和数据；用户通常有独立线路。但是是对电话通路的复用，早期DSL会占用电话线路
有线电视网络（Cable） 同轴电缆 共享有线电视网络进行宽带接入 多个用户共享接入网络资源：有源光纤网络AON（每个用户独立线路，速度快，但成本高，能耗大）和无源光纤网络PON（用户共享线路，成本低，能耗低）
FTTH 光纤 光纤直接接入用户家庭 带宽大、稳定、抗干扰能力强
无线局域网（WLAN） 无线电波 通过 Wi-Fi 等无线技术接入 覆盖范围较小，部署方便
广域蜂窝接入 无线电波 通过运营商基站接入 4G/5G，覆盖范围广，可移动接入

实际的家庭网络往往采用有线和无线等多种接入网技术混用（如光纤入户，家中采用局域网），而实际的企业网络则往往采用交换机与专线直接连入因特网

网络核心

网络核心的作用是将海量的端系统互连起来，解决进入网络之后，数据如何跨越大量网络设备，从一个端系统到达另一个端系统。可以理解为，网络核心就是有大量互联的路由器机器告诉链路构成的网络主体，负责在不同的端系统之间转发数据

端系统通过本地网提供商（Access ISP）接入Internet，然后网络提供商也要相互连接。一种选择是两两直接建立链路，但问题是后续加入的每个Access ISP也要和别的链接，导致可扩展性下降。另外一个选择则是定义全局ISP（Global ISP），每个本地的Access ISP链接本地全局ISP，全局ISP再相互链接。后续也出现了区域ISP（region ISP），链接Access ISP和Global ISP。

功能

网络的核心功能有两个：路由和转发

路由

负责计算从源主机到目的主机，数据应该经过怎样的路径，通过路由算法计算，结果存储在路由表里

转发

本地操作，将数据转发给下一个主机，强调数据该从哪个接口离开

网络核心组成

可想而知，网络核心最重要的两个组成部分就是路由器以及相应链路。

路由器（Router）：决定数据包应该往哪里走，以及将数据包从输入接口转移到合适的输出接口。
链路（Link）:在路由器之间传输数据。

网络核心的基本工作就是利用它们完成数据在网络核心中的转发

工作方式：分组交换

网络核心并不是简单地建立一条固定线路，然后让数据一直通过这条线路传输。Internet 最核心的通信方式之一就是：分组交换（Packet Switching）它的基本思想是：将应用产生的数据划分成一个个较小的数据块，每个数据块作为一个分组（Packet）在网络中独立传输，每个分组首部都含有地址，独立地选择传输路径。

选用这种传输方式是因为网络资源是共享的，如果每条网络通信都长时间单独占用其使用的线路，这会严重占用网络资源。同时如果每两个用户之间都建立一条专用线路，网络资源会产生巨大的浪费。

而分组交换允许不同用户的数据包共享同一条链路，按照一定规则交替传输自己的数据包。也即统计复用（Statistical Multiplexing）

总的来说，分组交换实现了主机之间端到端通信可由多个路径构成，不同的分组可共享的使用同一节点或链路。

其实还有一种技术电报交换。这个技术中主机持续以数据流发送，先呼叫建立连接，实现端到端的资源预留。预留的的资源包括：链路带宽资源、交换机的交换能力电路连接建立之后，物理通路被通信双方独占。不适用现在互联网这种大量用户、通信具有突发性的网络，遂应用大幅减少。
